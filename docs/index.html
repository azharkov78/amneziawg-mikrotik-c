awg-proxy — AmneziaWG для MikroTik

Контейнер для RouterOS (~300 КБ), который подключает штатный WireGuard-интерфейс MikroTik к серверу AmneziaWG. Шифрует сам роутер, контейнер только меняет вид пакетов. Поддерживает AmneziaWG 1.0, 1.5, 2.0, 3.0 и 3.1, подходит и бесплатный конфиг Cloudflare WARP.

Открыть конфигуратор

Конфигуратор работает в браузере офлайн: вставляете .conf из AmneziaVPN и получаете готовые команды для терминала MikroTik. Ключи никуда не отправляются.

Пойдёт ли на моём роутере

  • arm64 — hAP ax², hAP ax³, RB5009, CCR2004/2116/2216
  • arm — hAP ac², hAP ac³, RB4011, RB3011
  • armv5 — hEX refresh (E50UG), hEX S 2025 (E60iUGS), hAP ax S (E62iUGS), отдельный образ
  • x86_64 — CHR
  • Не поддерживается: MIPS (hEX, hEX S, hAP ac lite, hAP lite, RB2011) и tile (CCR1xxx) — для них у RouterOS нет пакета container

Нужны RouterOS 7.4+ с пакетом container и 16 МБ свободной RAM. На RouterOS 7.22+ образ ставится из реестра ghcr.io/timbrs/awg-proxy:latest и обновляется одной командой.

In English

awg-proxy is a ~300 KB RouterOS container that connects the native MikroTik WireGuard client to AmneziaWG servers (AWG 1.0–3.1, Cloudflare WARP). Install it with the offline configurator; see the English README and FAQ. The old Go version, timbrs/amneziawg-mikrotik, is deprecated.
